# 电缆隧道接头巡检复核台

Flask + SQLite + 原生 JavaScript（零前端构建、零 CDN 依赖）。巡检员录入线路里程、
接头、巡检批次、负荷区间、测温距离、温差读数、设备校准版本以及复测/人工复核记录；
系统按 **同一接头 + 同一批次** 对齐观测，区分「可比较 / 证据不足 / 相互矛盾」，
生成带原因的风险结论与处置清单，并支持批次报告封存。

## 一条命令启动

```bash
docker compose up --build
```

启动后浏览器访问： <http://localhost:5000>

首次打开后，在「录入」页点击 **载入演示数据**，即可看到一个批次（`2026-09-A`）
下覆盖全部判定分支的 8 个接头。

本地无 Docker 时：

```bash
pip install -r requirements.txt
python wsgi.py        # http://localhost:5000
```

SQLite 数据文件位于 `data/cable.db`（容器中挂载为命名卷 `cable-data`，重建容器不丢数据）。

## 判定规则

对同一 `线路 + 里程 + 接头 + 批次` 下 **当前生效** 的观测做对齐：

| 对齐结果 | 条件 |
|---|---|
| 可比较 comparable | ≥2 条观测，测温距离差 ≤ **0.2 m**、负荷区间一致、设备校准版本一致 |
| 证据不足 insufficient | 仅 1 条观测；或观测之间距离/负荷/校准版本不一致，无法对齐 |
| 相互矛盾 contradictory | 可比较，但温差读数极差 > **3.0 K** |

可比较时按最大温差定风险：

- 高风险：最大温差 ≥ **10.0 K**（或读数相互矛盾）
- 中风险：6.0 K ≤ 最大温差 < 10.0 K
- 低风险：最大温差 < 6.0 K
- 证据不足：风险为「待判定」，给出重新对齐 / 补测处置项

阈值定义在 `app/analysis.py` 顶部（`DISTANCE_TOL`、`SPREAD_TOL`、`HIGH_TEMP`、`MEDIUM_TEMP`）。

每条结论都带文字原因和处置清单（`RETEST` 复测、`MANUAL_REVIEW` 人工复核、
`REALIGN` 重新对齐、`SUPPLEMENT` 补测等）；登记了晚于最新观测的复测/复核后，
对应处置项自动标记为已闭环。

## 不可覆盖与可追溯

- **原始记录不可覆盖**：观测与复核均为只追加。更正/补录是一条带 `supersedes_id`
  的新观测行，旧行保留并标记 `active=0`（界面上仍可见，带删除线与取代关系）。
- **更正只影响该接头**：新观测或新复核只会让对应「接头+批次」的当前结论失效，
  其他接头结论不变。
- **历史结论可追溯**：结论按版本保存（v1、v2……），失效时记录失效原因
  （如「观测 #17 更正/补录并取代 #3：距离录入笔误」）及取代它的新版本号，
  「证据链」页可查看完整版本链。

## 封存规则

- 封存报告把批次在封存时刻的接头、结论版本、观测/复核编号整体序列化为
  **固定 JSON 快照**；封存后再更正/补录不会改变报告内容（查看旧报告时会额外
  提示封存后发生漂移的接头）。
- **每个高风险接头都必须具备「当前复测」或「明确人工复核意见」**。
  「当前」指复核时间不早于该接头-批次的最新观测——过期复测不算数。
- 任一高风险接头未覆盖，整份报告 **不得封存**，接口返回 422 并列出阻断接头；
  「封存报告」页可先做「封存预检」查看阻断清单。

## 页面

- **录入**：观测读数（可从证据链对任意生效记录发起「更正/补录」）、复测/人工复核；
  提交后即时返回结论版本与处置闭环状态。
- **复核台**：按批次/线路查看接头卡片，按高风险→待判定→中→低排序，
  顶部为风险汇总（含高风险未闭环数）。
- **证据链**：按线路查看每个接头的原始观测、更正取代链、复核记录、
  全部历史结论版本及失效原因。
- **封存报告**：批次封存预检、封存、已封存报告列表、固定快照详情与封存后漂移提示。

## HTTP API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/lines` `/api/batches` `/api/joints` | 基础字典 |
| POST | `/api/observations` | 追加观测（带 `supersedes_id`+`correction_note` 即更正/补录） |
| GET | `/api/observations` | 查询观测（含已被取代记录） |
| POST | `/api/reviews` | 追加复测（`kind=retest`）或人工复核（`kind=manual`） |
| GET | `/api/reviews` | 查询复核记录 |
| GET | `/api/board?batch=&line_name=` | 复核台：当前结论、风险、处置闭环 |
| GET | `/api/evidence?line_name=&batch=` | 证据链与结论版本/失效原因 |
| GET | `/api/reports/preview?batch=` | 封存预检（含阻断接头清单） |
| POST | `/api/reports` | 封存批次快照（不满足条件返回 422） |
| GET | `/api/reports` `/api/reports/<id>` | 报告列表 / 固定快照详情（含漂移） |
| POST | `/api/admin/seed` | 写入演示数据（已有观测则跳过） |

```
static/
  app.js          # 原生 JS 前端
  style.css
templates/
  index.html
wsgi.py           # gunicorn 入口

```
